# Zyll财经

财经数据网站，包含以下板块：

- **经济日历**：预测值、公布值，重要性分为"非常重要 / 重要 / 一般"三级；显示各国节假日和美股/期货/外汇休市；悬停（手机点击）查看指标解释和历史折线图。
- **美股暗盘**：FINRA 场外成交、各暗池机构排行、个股详情，可选接入实时大单。
- **美期**：股指期货报价、CFTC 机构持仓。
- **持仓分析（原“自选”，可设为会员）**：美股持仓，结合外汇交易中心汇率实时计算含汇损的盈亏；可选择“扣除通胀”（按 CPI 折算成今天的购买力）和“计入汇率”。
- **行情**：实时指数（每人自选最多 5 个）、我的个股、成交最多（按成交额/成交量），点击可跳转第三方网站看 K 线。

界面为毛玻璃风格，支持中英双语和四个时区。前台公开浏览，用户用邮箱注册；独立后台地址为 `/zylladmin`。

## 启动

服务器需要先安装 Docker：

```bash
curl -fsSL https://get.docker.com | sh
```

解压后进入项目文件夹，运行：

```bash
docker compose up -d --build
```

- 前台：`http://服务器IP:8088`
- 后台：`http://服务器IP:8088/zylladmin`

注意：需要在云服务器的安全组里放行 TCP 8088 端口。

## 第一次进入后台

访问 `/zylladmin` 会自动进入安装向导：

1. **创建管理员**：设置用户名和密码。
2. **绑定谷歌验证器**：用 Google Authenticator（或其他 TOTP 应用）扫码，输入 6 位动态码完成安装。

之后每次登录后台都需要"密码 + 动态码"。

> 部署后请第一时间完成安装。在你安装之前，任何人都可以访问这个向导。
>
> 想防止别人抢先安装，可以在 `.env` 里写一行 `ZYLL_INSTALL_TOKEN=自定义口令`，安装时需要输入这个口令。

所有设置保存后立即生效，不用重启。

## 应急命令

以下命令在服务器上运行，运行后执行 `docker restart zyll` 生效。

| 情况 | 命令 |
|---|---|
| 开启 Cloudflare 验证后进不去后台 | `docker exec zyll python -m app.cli disable-turnstile` |
| 忘记后台密码，或手机丢失无法获取动态码 | `docker exec zyll python -m app.cli reset-admin`（删除所有管理员，然后重新进入安装向导） |
| 查看有哪些管理员 | `docker exec zyll python -m app.cli list-admins` |

## 可选的 .env 文件

在项目文件夹里新建 `.env` 文件，每行写一项：

```
PORT=9000                                              # 换端口
PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple   # 国内服务器构建慢时使用
ZYLL_INSTALL_TOKEN=自定义口令                           # 安装向导需要输入此口令
```

改完运行 `docker compose up -d` 生效。只有改了 `PIP_INDEX_URL` 时，才需要加 `--build`。

## 持仓分析与连汇盈亏

用户（可设为仅会员）可以在“持仓分析”添加美股，记录每笔买入、卖出（日期、股数、价格、成交汇率、手续费、备注），系统按本币实时计算：

- **总市值、持仓盈亏、今日盈亏、已实现盈亏**，并把盈亏拆成“股价部分”和“汇率部分”，一眼看出汇损/汇兑收益。
- **本币**由用户自己选（人民币、港币、新加坡元、欧元、英镑、日元、澳元、加元、瑞郎、美元）；切换本币时，历史成交汇率会按交叉汇率自动换算。
- **汇率**取中国外汇交易中心的银行间即期报价，可选“中间价”或“卖出美元可得价”（更保守）。
- 成本采用加权平均法；“今日”以上一美股交易日收盘（美东 16:00）时的股价和汇率为基准。
- 可以设置目标价、止损价，并导出交易记录 CSV。

使用前需要：

1. 后台 →“持仓分析”：确认已开启，并选择“仅会员”或“所有注册用户”可用。
2. 后台 →“用户与注册”：给用户开通会员。
3. 实时价格：后台 →“数据源”→“美股实时行情”（默认已开启，用新浪轮询）。想要更快的逐笔推送，填入免费 Key，几家可以同时用：
   - Finnhub：https://finnhub.io 免费注册，约 50 只；
   - Alpaca：https://alpaca.markets 免费注册，约 30 只；
   - Polygon：实时需付费。
   股票按“来源顺序”依次分给已连上的供应商，剩下的交给新浪轮询（新浪失败时自动改用腾讯）；某家断线时它负责的股票自动转给轮询。

每笔交易可以选自己的货币对（例如用港币账户买入就选 USD/HKD）。卖出只能冲减同一货币买入的持股；汇总时按当前汇率折成“汇总本币”。

已知限制：未处理美国节假日；刚部署的第一个交易日还没有“昨收汇率”快照，今日汇率基准用最早记录的汇率代替（页面会注明）；当天按当前汇率录入的买入，今日汇率部分接近 0 属于正常；外汇交易中心的报价时段约为北京时间 9:30 到次日 3:00，其余时间沿用最后一笔报价。

## 节假日与休市

- 美股休市日和 13:00 提前收盘按纽交所规则计算（不联网也准确），后台“数据源 → 节假日与休市日”可补充临时休市日（如国丧日）。
- CME 股指期货在美股假日的提前收盘/休市据此推算；欧元区按 TARGET2 规则计算。
- 各国公众假日从 Nager.Date 下载，中国法定假日和调休（外汇交易中心休市）从 holiday-cn 下载。
- 用到交易日的地方都已考虑假日：盘前/盘中/盘后判断、持仓分析“今日盈亏”的昨收基准、行情刷新频率。

## 行情页

- 指数：未登录显示道琼斯、纳斯达克100、标普500、罗素2000、VIX；登录后可从 16 个指数中自选最多 5 个。
- 我的个股：登录后添加（输入代码或公司名联想），显示最新价、盘前/盘后价（仅盘前盘后时段）、开高低、昨收、成交量、成交额、市值。
- 成交最多：新浪美股排行 + 常见活跃股票池，按成交额或成交量排序，30 秒刷新。
- 点击代码会询问用哪家网站（新浪、雪球、富途、Yahoo、TradingView）查看 K 线，并提示“即将离开本站”的风险，在新窗口打开。

## 经济日历日程库

- 主要经济体的重要发布时间是固定的：内置的官方日程（`backend/app/econ_schedule.py`）启动时写入并锁定，Forex Factory 提前 3 个月按月抓取的日程也写入日程库；之后的抓取只更新预测值、前值和公布值，“下一个非常重要数据”不会再因为抓取时有时无而跳来跳去。
- 同一事件按“货币 + 标题 + 前后 36 小时”对应，不会因为来源或时间不同出现重复；抓取源删除的事件自动隐藏。
- 抓到的时间与库里不同时：锁定的事件只在后台提示“时间变化”，由管理员采用或忽略；未锁定的抓取事件连续两次看到同一新时间（且离公布还有半小时以上）才改期。
- 到点后还没公布值的事件继续显示“已到公布时间，等待数据…”（最多 30 分钟），公布后再显示 2 分钟，然后才轮到下一个。
- 后台“日历日程”页：按时区、日期、货币、来源、重要性筛选；添加、编辑、删除（删除后抓取不会再加回来）、恢复、锁定 / 解锁；CSV 批量导入（时间按所选时区，自动处理夏令时）；“立即抓取未来 3 个月”。

## 经济日历详情

电脑上鼠标悬停在某条数据上自动弹出详情，手机上点击从底部弹出：中文名称和含义解释、通常对货币的影响方向、最近若干期“公布值 vs 预测值”折线图和数值表。历史数据来自本站积累，并会在空闲时自动回填近半年（每分钟抓一周，不影响正常刷新）。

## 运行日志

后台“运行日志”页可查看程序的信息、警告和错误（含完整堆栈），包括数据源抓取失败、接口 500 错误、慢请求、后台操作记录，支持按级别筛选、搜索、自动刷新和下载日志文件（服务器上的 /data/logs/zyll.log，5 MB 轮转保留 5 份）。

## 持仓分析：分析卡片、总资本、通胀与汇率开关

- 四张汇总卡片（总市值、今日盈亏、持仓盈亏、总盈亏）都带走势折线；电脑上鼠标悬停、手机上点击会弹出分析：
  - 总市值：较上一交易日 / 近 1 周 / 近 1 个月变化、区间最高最低、最大盈亏回撤、第一大持仓、持仓权重、市值与成本走势；
  - 今日盈亏：较昨日、较近一周日均、股价与汇率拆分、近 20 日每日盈亏柱状图、今日贡献最大的股票；
  - 持仓盈亏：汇率影响占比、盈利持仓数、走势、贡献最多/最少的股票；
  - 总盈亏（持仓 + 已实现）：走势、已实现盈亏按股票拆分。
- 历史走势用 Yahoo 日收盘价和日汇率按交易记录回算近 3 个月，之后每天收盘自动补充（后台“数据源 → 持仓分析历史”）。
- 总资本：多币种现金 + 美股持仓，全部按当前汇率折合汇总本币，并显示各项占比。
  - “入金 / 出金 / 换汇”手工记录；换汇时显示你的成交价与当前中间价的差。
  - 买卖记录自动联动现金：买入从该笔交易货币对的现金里扣除（含手续费），卖出加回。
  - 某种现金为负时提示可能漏记了入金或换汇。
- “持仓分析”和“行情 → 我的个股”是同一份清单，任一处添加另一处同步；在行情删除时，有交易记录的股票会保留。点击代码同样可以跳转第三方网站看 K 线。
- 页面顶部两个开关（存在服务器上，网页和 App 同步），四张卡片、分析图表和每只股票的盈亏一起切换：
  - **扣除通胀**：通用通胀模型——每笔成本和卖出所得按付款货币所在地区的物价指数（人民币用中国 CPI、美元用美国 CPI、欧元用欧元区 HICP……）折算成今天的购买力，实际盈亏 = 市值 − 按今天购买力计算的成本。月度物价按优先级取数：管理员补录 > 官方指数（美国 FRED CPI-U）> 经济日历抓到的 CPI 公布值 > 世界银行年度通胀率 > 按最近 12 个月的速度推算；月与月之间按天插值。今日盈亏不受影响。
  - **计入汇率**：关闭后只看股价部分（持仓按买入时的平均成本汇率换算，已实现盈亏同理），不含汇率变化。
- 后台“通胀数据”页显示每个地区每月的数据来源、环比 / 同比，可以手动补录缺失的月份。

## 暗盘

- 全市场场外卖空占比：最新值、20 日均线及偏离、近 90 日分位、区间高低、成交量较 20 日均量，以及可切换 1 个月 / 3 个月 / 全部的交互图（悬停显示数值）。每日数据会自动回填近 3 个月。
- 关注列表：登录用户自动显示自己的自选（与自选、行情同步），未登录显示后台设置的关注股票。
- 每个板块都标注数据日期和最后更新时间。

## 会员与卡密

- 后台“会员”页开启会员模式；“卡密”页可以：
  - 随机生成卡密（7 天 / 30 天 / 90 天 / 365 天 / 永久 / 自定义天数，可设批次、前缀、兑换截止日期、备注，每次最多 5000 张），生成后可复制或下载；
  - 导入指定卡密（每行一个，可写“卡密,天数”，重复和格式错误会逐行报告）；
  - 按批次 / 状态 / 关键字筛选，停用、恢复、删除（已使用的卡密不可删除，留作记录），导出 CSV。
- 前台：账户菜单里显示“激活会员”；已是会员则显示“会员至 某日（点击续期）”，点击输入卡密续期，时长从到期日往后累加；永久卡变为永久会员。
- 卡密不区分大小写、空格和横线；同一张卡密并发兑换只有一人成功；每个账号 / IP 10 分钟内最多尝试 8 次，防止暴力猜卡密。
- 后台“会员”页可查看每次开通 / 续期记录；“用户与注册”页仍可手动开通。
- 会员模式关闭时，前台和 App 接口不返回任何会员信息，所有板块（包括自选）对登录用户开放。
- 原“付款接口”已移除。

## 安卓 App 接口

- 地址前缀 `/api/app/v1`，文档见 `docs/APP_API.md`（部署后也可访问 `/api/app/v1/docs`）。
- 登录用 Bearer Token（每台设备一个，可在 App 或后台“安卓 App”页下线）；改密码或停用账号后令牌立即失效。
- 网页的数据接口都可以通过 App 前缀访问（日历、行情、暗盘、美期、自选、总资本等）；App 前缀下忽略 Cookie，因此不需要网页的防伪造请求头。
- 实时推送：WebSocket `/api/app/v1/ws`（可只订阅部分主题），也可用 SSE。
- 后台可开关 App 接口、要求 App Key（请求头 `X-App-Key`）、发布新版本（最新版本号、最低可用版本号即强制更新、APK 地址、更新说明）。

## AI 导入券商结单

- 用户在“持仓分析”点“✨ AI 导入结单”，上传券商的交易记录或月结单（文字版 PDF、Excel .xlsx、CSV；配置了能看图片的模型时还支持截图、照片和扫描版 PDF）。一次可以选多个文件（例如几份日结单 + 月结单）。
- 流程：读取文件 → 隐去姓名、地址、邮箱、手机号，账号 / 订单号换成不可还原的代号 → 精简（去掉重复的页眉页脚、免责声明，加行号，AI 只回答行号不抄原文，省 token）→ AI 按缩写格式提取成交（含成交时间、订单号）、股息、费用、换汇、期初持仓 → 程序逐行校验和去重 → 用户核对、修改、勾选 → 试算 → 一次性写入（失败则一条都不写）→ 可整批撤销。
- **不会重复导入**：同一天 + 同一股票 + 同一方向的交易与已有记录（包括手动录入的）对账——先比订单号，再比数量、价格（和成交时间），最后比当天合计数量和均价。已经记录过的自动跳过（预览里默认隐藏，可以展开查看）；多出来又对不上的部分标出来，用户确认后才导入。多个文件之间也互相去重；同一批识别结果不能导入两次；对账单期间与以前导入的重叠时会提示。
- 程序会检查：
  - 日期、代码、方向、数量、价格是否合理；
  - 数量 × 价格是否与对账单金额对得上；
  - 是否美股（港股、期权等会标出且不导入）；
  - 代码是否在美股列表里；
  - 价格是否偏离当天收盘价（例如拆股前的价格）；
  - 是否与已有记录重复；
  - 卖出是否超过持有（按日期逐笔检查）；
  - 导入后现金是否变成负数。
- 汇率：用户只需记录一次换汇（例如 71000 元换了 10000 美元），导入的交易自动以换汇的加权平均成本作为成本汇率，并从美元现金里扣，不会重复扣人民币。
- 手动记交易时也可以选“用之前换好的美元”，汇率默认填换汇的平均成本。
- 后台“AI 导入”页可以：
  - 开关这个功能，设置“仅会员可用”；
  - 设置每人每天、全站每天的识别次数，以及文件大小和页数上限；
  - 选择模型组合：“文字模型 + 图片模型”、“一个多模态模型同时处理文字和图片”（如千问 qwen3.7-plus / qwen3.8-max、Kimi k2.6、豆包 Seed 2.1）或“只用文字模型”；
  - 选择服务商（DeepSeek、通义千问北京 / 国际站、智谱、豆包、Kimi 或其他兼容 OpenAI 的接口），接口地址留空即用官方地址，模型可从推荐列表选、点“获取模型列表”或手动填写。默认文字模型 `deepseek-flash`（`deepseek-chat` / `deepseek-reasoner` 已于 2026-07-24 停用，升级后自动改用 `deepseek-flash`），图片模型 `qwen3.7-plus`；
  - 各家接口细节不同（千问新模型默认开启思考、JSON 模式限制、Kimi 固定温度、智谱图片格式、输出上限等）：程序默认流式调用并按服务商关闭思考；接口返回 400 时读出错误原因，自动去掉 / 调整对应参数重试，并记住这个模型的规则。“测试连接”会显示自动调整了哪些参数；
  - 查看调用记录和用量。
- 隐私：文件和识别结果只在内存中处理，30 分钟内清除，不写数据库；上传前用户必须勾选同意。隐私政策会自动写明使用的 AI 服务商（只写域名）。
- **网站前面有 Nginx / 宝塔 / 1Panel 等反向代理时**，请把上传大小上限调到不小于后台设置的文件上限，例如 Nginx 加 `client_max_body_size 12m;`（默认只有 1MB，超过会直接返回 413）。识别在后台进行、网页每 1.5 秒查询一次进度，不受代理超时影响。

## 找回密码与 App 网页登录

- 登录框里有“忘记密码？”，会发送 30 分钟有效的重置链接。邮件模板可在后台“邮件”里修改；需要先配置 SMTP。重置后该账号所有网页会话和 App 令牌立即失效。
- 后台开启“前台登录时验证”（Cloudflare Turnstile）后，安卓 App 不能再直接提交密码：
  - App 会打开浏览器进入本站登录页，人机验证、注册、找回密码都在网页完成；
  - 用户点“授权登录”后自动回到 App（PKCE 一次性授权码，App 拿不到密码）；
  - 登录方式可在后台“安卓 App”页修改。

## 安卓 App 源码

- `android/` 目录是原生安卓 App（Kotlin + Jetpack Compose），包含经济日历、行情、自选（含交易与总资本）、暗盘·美期、账号与会员卡密、版本更新。
- 编译方法见 `android/BUILD.md`：用 Android Studio 打开 `android` 文件夹，在 `local.properties` 里填 `zyll.serverUrl=https://你的域名`，然后点运行或打包。
- `android/` 不参与 Docker 镜像构建，部署网站时可以忽略。

## 隐私与合规（GDPR）

- 前台页脚有“隐私政策”页面，内容按后台“隐私与合规”页的设置自动生成（数据控制者、联系邮箱等请务必填写）。
- 登录安全记录（防欺诈）：注册、登录成功/失败、退出、改密码时记录 IP、国家/地区（需经过 Cloudflare）、浏览器、设备特征和风险标记（新设备、新网络、新国家、多次失败、自动化浏览器）。默认保留 180 天。依据为 GDPR 第 6(1)(f) 条正当利益。检测到新设备或新国家登录时，可自动给用户发提醒邮件。
- 诊断数据：只在访客同意性能 Cookie 后收集，包括加载各阶段耗时、核心网页指标、接口耗时、错误堆栈、网络与设备环境等；不关联账号，IP 截断保存；后台“诊断数据”页底部可查看收集到的原始数据，并导出 JSON。
- 数据导出/删除：用户可在账号菜单中“导出我的数据”或“删除账号”；管理员可在“用户与注册”页导出单个用户，或在“隐私与合规”页一键导出全部用户数据。
- 注意：GDPR 要求“数据最小化”，所以本系统只收集与防欺诈、故障诊断直接相关的数据，不做画布/音频等隐蔽指纹。

## 邮件模板

后台“邮件”页：SMTP 设置，以及邮箱验证、注册欢迎、新设备登录提醒、会员开通通知四个模板。主题和正文都可自定义，支持 {site_name}、{email}、{link}、{ip} 等占位符，可另外填写 HTML 正文；每个模板都能预览和发送测试邮件。

## 节省服务器资源

- 实时价格每 0.5 秒合并推送一次，只推送有变化的代码；所有用户共用同一路订阅。
- 盈亏在浏览器里计算，服务器只推送价格和汇率；页面只更新变化的单元格。
- 报价没有变化时不推送。经济数据只在公布前后高频检查。
- 两分钟无人访问时行情采集自动放慢；五分钟无人访问时断开实时行情连接、停止轮询；有人打开网页立即恢复。
- 被数据源限流（HTTP 429）时按对方要求的时间暂停，记录保存在数据库里，重启容器也不会马上重复请求。

## 技术说明

- **运行方式**：整个网站是一个容器，由 Python（Starlette + Uvicorn）同时提供前台、后台、接口和实时推送（SSE），并运行采集任务。
- **数据库**：SQLite。
- **依赖**：只有两个 Python 依赖包；谷歌验证器、二维码、密码哈希都用 Python 自带的库实现。
- **目录结构**：
  - `backend/app/settings.py`：所有可在后台编辑的设置项。新增设置项后，后台会自动生成对应的表单。
  - `backend/app/collectors/`：数据源，一个文件对应一个。
  - `backend/app/api_public.py`：前台接口。
  - `backend/app/api_admin.py`：后台接口。
  - `backend/app/collectors/market.py`：行情（新浪/腾讯/Yahoo）；`backend/app/holidays.py`：节假日；`backend/app/runlog.py`：运行日志。
  - `backend/app/pnl.py` 与 `frontend/js/pnl.js`：同一套盈亏算法的 Python / JS 版本（有一致性测试）；`backend/app/history.py`：历史市值；`backend/app/lists.py`：清单同步。
  - `backend/app/members.py`：会员与卡密；`backend/app/api_app.py`：安卓 App 接口。
  - `backend/app/api_portfolio.py`：自选股接口；`frontend/js/pnl.js`：连汇盈亏计算。
  - `frontend/`：前台页面；`frontend/admin/`：后台页面。
